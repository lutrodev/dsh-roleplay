# Roleplay 我的人设

“我的人设”用于描述用户在故事中的身份。可以保存姓名、性别、年龄、外貌、身份、说话方式、背景、爱好和头像，并在不同对话中复用。

当前绑定人设会同时进入 Writer 的完整 Context Build 和 Chat 父代理的有限身份上下文；提交后的回复选项生成器也使用这份冻结的角色上下文识别用户控制身份。

插件提供人设的创建、编辑、默认选择和删除功能。每个对话可绑定一份人设；头像会清理原始图片元数据后保存，未填写的身份细节保持开放。

Agent 模式使用固定字段 `name`、`description`、`personality`、`scenario`、`firstMessage` 和 `tags`；背景、外貌与身份等事实写入 `description`，未知字段会明确报错而不会被静默丢弃。

描述快捷项会从当前光标处插入；新增下一项时会另起一行，光标停在字段名后的冒号处，方便立即继续填写。

资料库首次初始化时会创建名为“用户角色”的占位人设；已有或用户编辑过的人设不会被改写。

人设头像只在列表项接近可见区时读取，并按人设修订在当前连接内有界复用；修改头像后会使用新修订重新读取。
