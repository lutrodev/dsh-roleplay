# Roleplay 资料库

为角色卡、世界书、我的人设、创作预设和文风提供统一的侧栏入口与资料选择界面。

创建新故事时，可以组合所需资料，选择角色卡开场、自定义开场或跳过开场。对话顶部以只含图标、标题和指向符号的紧凑入口打开会话 Wiki 与 Prompt 工作台：前者用于查看当前资料和状态，后者用于调整下一次回复参考的内容与顺序；资料卡和回复预览同时使用颜色与语义图标区分角色卡、世界书、我的人设等资料类型。会话 Wiki 中未绑定或已失效的角色卡、世界书、人设、预设和文风会提供“选择并绑定”入口，只更新当前资料类型；资料的创建和内容编辑仍由侧栏资料库负责。当前状态数量按实际展示的末级变量项统计，嵌套对象和列表本身仅作为分组。

五类共享资料都不是生成前置条件。会话可以在零绑定时继续；某项绑定后来不可用时，界面会说明它已从后续回复资料中跳过，并允许手动重绑。局部绑定不会重新校验、清理或改写其他资料引用。

Roleplay 对话正文只呈现故事消息和必要的运行反馈。Harness 记录的系统提示词快照继续保留在 Session 日志和提示词检查界面中，但不会作为“系统提示词”条目插入故事正文；普通 Harness 会话仍沿用原生展示。
