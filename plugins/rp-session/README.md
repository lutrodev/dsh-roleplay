# Roleplay 会话配置

为每个 Roleplay 对话保存独立设置，包括角色卡、世界书、我的人设、创作预设、文风、开场白、Chat／Agent 模式、Writer 模型覆盖和 Prompt 排列。

资料以当前版本参与下一次回复，已经生成的历史内容保持不变。用户可以在对话中更换或取消资料，也可以保留自定义 Prompt 内容与顺序。

Writer 默认不在会话中复制全局设置，而是在每次新回复开始时读取最新全局默认值。用户为当前会话选择其他模型、推理强度或“跟随当前对话”后，只有该 Writer 路由覆盖会写入会话事件；恢复“使用全局默认”会移除覆盖。任务子代理不读取这项会话设置。
