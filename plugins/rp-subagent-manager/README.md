# Roleplay 子代理

管理故事正文 Writer 的全局默认路由与可选任务子代理。Writer 负责生成每次故事回复；任务子代理可以按用户配置承担剧情规划、资料检索、润色等独立工作。

尚未单独设置 Writer 的会话会在每次新回复开始时读取最新全局默认值；会话页可只为当前对话覆盖 Writer 的模型与该模型支持的推理强度，或恢复全局继承。每个任务子代理仍只使用目录中自己的全局设置，可以配置名称、工作说明、调用条件、模型、推理强度和只读能力，并可单独启停；Writer 的会话覆盖不会扩散到这些任务子代理。

任务在隔离上下文中运行，结果由主 Agent 决定是否采用，不会自行修改故事或替代 Writer；本轮用户附带的图片会由 Core 以原生附件引用自动传给 Writer 和任务子代理。
