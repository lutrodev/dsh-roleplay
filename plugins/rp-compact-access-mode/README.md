# 输入栏访问模式仅图标

这是一个可独立安装的浏览器显示插件。在所有输入栏宽度下，访问模式按钮都只保留当前模式图标，不再显示模式名称和下拉箭头；点击打开菜单、权限切换与确认流程均保持不变。

插件保留按钮原有的完整无障碍名称，因此收起后屏幕阅读器仍会读出“访问模式，当前：Workspace Write”等当前状态。没有内置图标的自定义访问模式不会被强制收起，以免控件失去可辨识内容。

可通过本目录的 `cordis.patch.yml` 单独安装，也可随 `dsh-roleplay` 默认组合加载；使用默认组合时，可在 Roleplay 设置的“功能”页通过“访问模式仅图标”卡片启停。插件只注入随 Cordis 生命周期挂载和卸载的样式，不修改 Harness 源码、会话数据或权限策略。
