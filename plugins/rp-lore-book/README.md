# Roleplay 世界书

世界书用于补充故事的世界设定、人物信息和重要规则。插件提供独立资料库，可创建、导入、编辑、排序、复制、启停和删除条目，也可以在一个对话中组合多本世界书。

条目支持常驻、关键词触发、大小写匹配、递归激活、概率、扫描深度和变量条件。变量条件默认用“变量分组、完整路径、比较方式、值”的常用表单填写，只引用会话中已经存在的变量，不创建或绑定变量；组合条件仍可在高级条件中编辑。通过界面或 Agent 模式原生创建、编辑条目时，每条内容都必须有可读名称、非空正文、明确分类，以及常驻或主关键词触发方式；原生接口会拒绝未知字段和无效类型，避免保存成功后才发现字段被忽略或条目永不启用。导入缺少名称的旧格式世界书时仍会生成兼容名称。资料库按加入时间倒序显示，最近导入或创建的世界书位于最前，后续编辑不会改变顺序。选择文件后，导入按钮会持续显示进度状态并避免重复选择，直到本次导入完成。兼容常见 SillyTavern 世界书字段以及角色卡内嵌世界书，并会按“世界设定、扮演指导、重要规则”三类内容加入故事上下文。
