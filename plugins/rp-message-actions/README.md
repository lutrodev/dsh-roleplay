# Roleplay 消息操作

为 Roleplay 对话提供复制、行内编辑、删除、重新生成和从指定位置新建对话等操作。用户消息由同一条 Roleplay 操作栏承载时间、复制、编辑与删除；只有这条操作栏实际挂载并接管公共消息节点时，才会隐藏 Harness 原生时间／复制栏，避免重复显示或影响标准对话。已中断或失败但仍有可读正文的回复也可以继续处理。

删除或重新生成会同步调整当前可见故事和相关会话变量，但不会撤销已经保存到共享资料库的角色卡、世界书、人设、预设或文风。删除助手消息后，触发该回复的用户消息、头像与操作条继续保留，可以直接编辑、删除或重新生成；编辑带图片的用户消息时，原附件会保留。

剧情提交失败时，界面保留与失败提交配对的正文和恢复操作；后续模型产生的空白占位或确认文本不会替代这段可恢复正文。提交纠错成功后，正文操作节点会持续跟随 Chat 投影的最终排序重新确认其所属消息，避免工具专用重试的临时空行在界面重排期间把原正文永久隐藏。

旧版本中曾因创作预设已删除或无法读取而形成的失败记录，失败尾部会说明该预设现已跳过，并同时提供“重新生成”和“重新选择预设”。当前运行时不会再让这类可选资料阻断生成；恢复沿用 Session 原生资料绑定命令，已有消息与会话变量不变，也不会静默切换到新的默认预设。
