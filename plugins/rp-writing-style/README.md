# Roleplay 文风

文风用于保存纯表达层面的写作要求，例如人称、视角、句法节奏、叙述焦点、对白、人物反应、动作空间、感官描写和修辞偏好。内置“通用叙事”默认锚定主角的第三人称限知视角，让叙述、对白、行动与可见反应自然交织，不引导书写主角内心；配角未说出口的想法只由创作预设中可独立停用的“配角心声”控制。对白按说话人与叙述焦点清楚分段，连续短对话可以独立成段，同时避免长期等长往返、惯用标签或相同反应反复维持节拍。人物形象影响场景时，会把有辨识度的样貌、神态与衣着融入观察、动作和互动，帮助用户代入和想象。

插件提供文风的创建、编辑、默认选择和删除功能。一个对话可以组合多条文风并调整顺序；文风只控制表达方式，剧情规则、连续性、信息释放、角色行为、收束和正文篇幅由创作预设负责。默认文风根据当前人物、场景与题材调整措辞、密度和节奏，观察落点、句法和段落结构由当前内容决定。

Agent 模式只接受 `name`、`description` 和 `content`，实际规则必须写入非空 `content`；`instructions`、`requirements` 等别名会明确报错，不会被静默忽略。
