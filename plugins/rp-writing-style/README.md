# Roleplay 文风

文风用于保存纯表达层面的写作要求，例如人称、视角、句法节奏、叙述焦点、对白、内心、动作空间、感官描写和修辞偏好。内置“通用叙事”默认锚定主角的第三人称限知视角，让叙述、对白与内心沿同一因果节拍自然交替，但不默认引导主角内心独白；对白按说话人与叙述焦点清楚分段，允许短对话独立成段，但避免长期形成等长、等距的单句往返。人物形象影响场景时，会把有辨识度的样貌、神态与衣着融入观察、动作和互动，帮助用户代入和想象。设定与线索随人物接触逐步显露，避免在同一处密集开启无关内容。

插件提供文风的创建、编辑、默认选择和删除功能。一个对话可以组合多条文风并调整顺序；文风只控制表达方式，剧情规则、连续性和角色行为由创作预设负责。默认文风不设置字数、段数或对白比例，篇幅由完整呈现本轮必要叙事节拍决定。一个场景可以跨越多轮，但过程节点必须已有可读进展，不会在第一层反应后截断，也不会为一次写完场景而过度推进。文风不强制追加新秘密和更大危机，也不复用近期回复的观察落点、句法、段落节奏或收束形式。

Agent 模式只接受 `name`、`description` 和 `content`，实际规则必须写入非空 `content`；`instructions`、`requirements` 等别名会明确报错，不会被静默忽略。
