# Roleplay 文风

文风用于保存纯表达层面的写作要求，例如人称、视角、句法节奏、叙述焦点、对白、人物反应、动作空间、感官描写和修辞偏好。内置“通用叙事”默认锚定主角的第三人称限知视角，让叙述、对白、行动、内心与可见反应自然交织。重要过程以正在发生的场景呈现，日常过程与过渡适度压缩；细节、句式、动作、感官和修辞都服从当前焦点与节奏，不按禁止项清单机械规避。主角内心默认融入第三人称叙述，只在念头需要成为瞬间焦点时直接呈现；配角未说出口的想法仍由创作预设中可独立停用的“配角心声”控制。

插件提供文风的创建、编辑、默认选择和删除功能。一个对话可以组合多条文风并调整顺序；文风只控制表达方式，剧情规则、连续性、信息释放、角色行为、收束和正文篇幅由创作预设负责。默认文风根据当前人物、场景与题材调整措辞、密度和节奏，观察落点、句法和段落结构由当前内容决定。

Agent 模式只接受 `name`、`description` 和 `content`，实际规则必须写入非空 `content`；`instructions`、`requirements` 等别名会明确报错，不会被静默忽略。
