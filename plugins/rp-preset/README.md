# Roleplay 创作预设

创作预设用于保存可复用的故事规则与写作任务，例如用户参与方式、角色自主性、连续性、剧情推进、自检和输出要求。内置“示例预设”以沉浸连续性、人物关系积累和选择性信息释放组织长程故事。一个场景可以跨越多轮；每轮聚焦当前最有分量的矛盾、互动、行动或发现，让人物回应、彼此作用与直接后果自然形成清楚、可继续的进展，而不把这些内容固化为顺序模板。篇幅由“格式要求”单独维护：除非用户另有指定，默认采用中等偏长的篇幅，不固定字数、段数或对白比例。预设还会根据当前内容组织推进、转折与收束，并提供可独立停用的“配角心声”栏位：主叙事仍锚定主角，只在确有叙事收益时短暂展示一名配角未说出口的想法。

示例预设明确允许 Writer 依据既有人设、当前情境和用户意图，主动写出主角的对白、即时反应、日常行为与行动延续；用户扮演主角时，仅将重大或不可逆选择保留给用户。其他角色默认由 Writer 主动表现，用户临时扮演或导演某个角色时仍可自然补全执行过程、互动与后果。人物选择与故事因果导向暴力、伤亡或血腥场面时，这些内容会按题材、视角和场景所需真实发生，不为保护角色改成虚惊或迅速复原，也不为刺激无端加重。人物的自我辩解只作为人物立场呈现；事件忠于实际行为、权力关系、受影响者体验与既成后果，不因角色魅力或故事舒适度擅自添加开脱、悔意、原谅、惩罚或救赎。

首次初始化会创建内置的“示例预设”并设为默认；之后新建预设会像新建文风一样直接进入空白编辑器，不再选择空白或示例起点。提示文本未编辑的旧版示例会保留资产、已有栏位 ID 与分组标签设置并升级内容，新增栏位使用新 ID；用户修改过提示文本的预设不会被覆盖。编辑器可以自由新增、删除、排序和调整栏位；每个栏位还能设置是否默认使用 `<section>`／`<item>` 分组标签，会话首次使用时继承该值，之后可在“回复资料”中独立调整。插件还支持把 SillyTavern Chat Completion 预设按语义转换为创作预设与独立文风。

Agent 模式更新预设时必须提交读取到的完整栏位数组，并保留每个栏位的 UUID、说明、正文、位置和分组标签布尔值；缺字段、错字段或无效 UUID 会明确报错，不会再静默生成新栏位 ID、清空内容或重置分组设置。
