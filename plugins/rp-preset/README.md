# Roleplay 创作预设

创作预设用于保存可复用的故事规则与写作任务，例如用户参与方式、角色自主性、连续性、剧情推进、自检和输出要求。

首次初始化会创建内置的“示例预设”并设为默认；之后新建预设会像新建文风一样直接进入空白编辑器，不再选择空白或示例起点。提示文本未编辑的旧版示例会保留资产、栏位 ID 与分组标签设置并升级内容，用户修改过提示文本的预设不会被覆盖。编辑器可以自由新增、删除、排序和调整栏位；每个栏位还能设置是否默认使用 `<section>`／`<item>` 分组标签，会话首次使用时继承该值，之后可在“回复资料”中独立调整。插件还支持把 SillyTavern Chat Completion 预设按语义转换为创作预设与独立文风。

Agent 模式更新预设时必须提交读取到的完整栏位数组，并保留每个栏位的 UUID、说明、正文、位置和分组标签布尔值；缺字段、错字段或无效 UUID 会明确报错，不会再静默生成新栏位 ID、清空内容或重置分组设置。
