# Roleplay 会话变量卡片

这是一个完全只读、独立装载的浏览器展示扩展。启用后，它会在当前对话最新一次成功的助手回复下方展示 `rp/state` 的完整当前值，并使用变量定义中的标题、说明、结构和顺序提升可读性。

- 只展示当前状态，不保存副本，也不修改变量或 Wiki。
- 整张卡片默认收起；展开后，长文本仍可以单独展开。
- `rp/state/activity` 中最近一次成功回复的变化会以“本轮更新”轻量标记，并显示为“之前值 → 当前值”；未变化字段仍只显示当前值。
- 删除或重新生成消息时，展示位置会跟随当前有效的会话表面回退。
- 插件在新配置中默认启用，由“设置 → Roleplay → 功能 → 对话”中的“会话变量卡片”统一管理；启用时会自动补齐“会话变量”前置功能，已有配置继续遵循用户保存的开关状态。

Host 端不注册服务、RPC、存储或写入操作。浏览器端仅消费 Harness 的公开 Conversation Node 与 Session Projection 接口，因此停用插件不会影响变量数据和已有对话。
