# Roleplay 功能管理

dsh-roleplay 的推荐安装入口。它把整套 Roleplay 能力加入 DeepSeek Harness，并在设置中提供统一的功能、Skills 和系统提示词管理。

会话总结属于始终启用的核心组件：它随 Roleplay 模式装载，并和其他核心组件一起以名称、版本和简介卡片显示，不提供独立开关。达到上下文压力、手动压缩或溢出恢复时，它使用 Roleplay 专用总结并向 Writer 提供独立的“会话总结”上下文。

可以分别启用角色卡、世界书、我的人设、创作预设、文风、会话变量、MVU 兼容、任务子代理、快捷回复、消息操作、会话变量卡片、头像和对白高亮。停用功能不会删除已经保存的资料、快捷回复或对话。

“会话变量卡片”在新配置中默认启用；已有配置继续遵循用户保存的开关状态。0.1.5 新增的快捷回复、会话变量卡片和访问模式仅图标会先等待功能管理器读完保存的设置，再按同一份选择装载，避免界面状态与实际能力不一致；这个启动对账不会改写已有功能的开关。新版 DSH 的 app-owned Profile 会在启动阶段重放 `--patch` 并复用既有 Loader Entry；功能管理器会在这次替换完成后再次对账，确保静态 patch 不会把已启用条目重新停用，其他功能开关也继续实际控制 Host 条目。会话变量卡片只在最新一次成功的助手回复下方展示完整当前变量，并自动启用作为前置能力的“会话变量”；关闭展示卡片不会停止变量维护，也不会改动会话 Wiki。

“快捷回复”功能卡同时提供设置入口。启用该功能后，可在 Roleplay 设置中直接新增、编辑、排序和删除快捷回复；未启用时入口保留为“启用后设置”，避免把管理操作塞进对话输入栏。

管理界面遵循 Harness 的可信 Host 边界：本机以及由 Harness 明确信任的远端地址可以读取和修改 Roleplay 设置、资料与消息；其他来源仍由 Harness 拒绝。
