# Roleplay 功能管理

dsh-roleplay 的推荐安装入口。它把整套 Roleplay 能力加入 DeepSeek Harness，并在设置中提供统一的功能、Skills 和系统提示词管理。

可以分别启用角色卡、世界书、我的人设、创作预设、文风、会话变量、MVU 兼容、任务子代理、快捷回复、消息操作、头像和对白高亮。停用功能不会删除已经保存的资料、快捷回复或对话。

“快捷回复”功能卡同时提供设置入口。启用该功能后，可在 Roleplay 设置中直接新增、编辑、排序和删除快捷回复；未启用时入口保留为“启用后设置”，避免把管理操作塞进对话输入栏。

管理界面遵循 Harness 的可信 Host 边界：本机以及由 Harness 明确信任的远端地址可以读取和修改 Roleplay 设置、资料与消息；其他来源仍由 Harness 拒绝。
