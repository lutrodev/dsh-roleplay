# 会话总结

为较长的 Roleplay 对话生成专用前文总结，避免早期剧情因模型上下文不足而直接丢失。

- 达到上下文压力时在后台总结较早对话，当前回复继续使用完整历史，不会等待总结完成。
- 总结输入沿用“写作回复／非写作回复”分类：前者作为已提交故事正文，后者只用于理解明确决定和约束，不会默认当作已经发生的剧情、角色对白或正文文风样本。
- 下一轮续写使用“会话总结 + 最近原文”，并让最近发生的内容优先于总结；包括真正撞到模型上下文上限的恢复路径在内，自动压缩至少保留最近一个已完成的用户—模型交换原文，没有更早前缀时不会牺牲这条模型回复。
- 支持 Harness 原有的手动压缩、溢出恢复、分支和回滚；失败、过期或没有缩短内容的总结不会生效。
- 原始消息仍保留在会话记录中，功能不会改写或删除人类可见的历史对话。

该组件随 Roleplay 核心能力自动加载，不提供独立开关；“会话总结”上下文可以在 Prompt 编排中调整顺序。
