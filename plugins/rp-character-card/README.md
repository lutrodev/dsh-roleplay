# Roleplay 角色卡

角色卡用于保存故事角色的身份、性格、背景、场景、对话示例、头像和开场白。插件提供角色卡资料库，可创建、编辑、删除角色卡，并为不同对话选择角色和开场。

当前绑定角色卡的生成正文同时进入 Writer 的完整 Context Build 和 Chat 父代理的有限身份上下文，便于识别角色并生成回复选项；角色卡仍只是信息包，不自动表示用户身份或控制权。

支持 Character Card V1、V2、V3 的 JSON 与 PNG 导入，也支持默认开场、备用开场和内嵌世界书。默认单文件上限为 20 MiB，完整导入文本上限为 2,000,000 个 Unicode 字符。资料库按加入时间倒序显示，最近导入或创建的角色卡位于最前，后续编辑不会改变顺序。选择文件后，导入按钮会持续显示进度状态并避免重复选择，直到本次导入完成。角色卡详情可以把当前已保存的修改与最新关联世界书导出为 Character Card V3 PNG；没有头像时使用透明 PNG 容器。导入时隔离的可执行提示不会重新写入导出文件，头像也会继续移除原始卡片和图片元数据。

列表使用可丢弃的进程内摘要缓存，首次重建时以固定并发读取资料；同一数据目录的导入、创建、编辑和删除都会在操作前后失效该缓存，不影响详情和生成上下文对实时资料的读取。浏览器仅在头像接近可视区时请求图像，并在当前连接内有界复用已读取结果。
