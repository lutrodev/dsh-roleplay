# 快捷回复

在 Roleplay 对话输入栏中显示紧凑的快捷回复按钮。点击按钮只会把内容插入当前光标或选区，不会自动发送；默认的 `“”`、`（）` 等成对符号会包住选中的文字，并把光标留在符号之间。

输入栏默认显示前三项；只有保存了第四项及更多内容时，桌面端才显示“更多快捷回复”菜单，窄屏则用同一个紧凑入口收起全部项目。按钮沿用 Harness 输入栏的原生尺寸与无描边工具样式。

自定义入口位于“设置 → Roleplay → 功能 → 对话体验 → 快捷回复”。启用功能后点击“设置快捷回复”，可以新增、编辑、排序、删除或恢复默认内容。保存后的内容通过 Harness Settings 持久化，并在所有 Roleplay 对话中共享；输入栏菜单不再承载设置操作。

插件最多保存 12 项快捷回复；单项名称最多 12 个字符，正文最多 2000 个字符，全部正文合计最多 8000 个字符。
